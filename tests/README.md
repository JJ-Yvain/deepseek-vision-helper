# 验证体系说明(科学验证,可迭代,走向自我验证)

基于测试方法论调研(测试金字塔、性质测试、突变测试、模糊测试、契约测试、
故障注入、LLM eval、对抗测试)构建的分层验证体系。

## 分层结构(L0-L5)

| 层 | 文件 | 内容 | 速度/成本 |
|---|---|---|---|
| L0 单元/性质 | `test_unit.py` | 纯逻辑:配置加载、记账/跳过状态机、附件增量、版本自检、性质不变量(记账单调) | 秒级/免费 |
| L1 契约 | `test_contract.py` | hook payload 与 API 响应格式契约,防平台/供应商格式漂移 | 秒级/免费 |
| L1 模糊 | `test_fuzz.py` | 畸形/边界输入轰炸:空 payload、非 JSON、千张附件、超长文件名 | 秒级/免费 |
| L2 故障注入 | `test_fault_injection.py` | mock API 注入 500/429/401/畸形/超时,验证降级链、重试、建议物理隔离 | 秒级/免费 |
| 攻击集 | `test_adversarial.py` | 针对已知弱点定向攻击:建议泄漏、旧图混入、轮次混淆、多图轰炸、边界 | 秒级/免费 |
| 残图攻击集 | `test_stale_attachment.py` | 贴错图→删图→换图→提交,从未发送的旧图不得注入;含纯文本残留/续传/兜底新鲜度 | 秒级/免费 |
| MCP 通道 | `test_mcp_server.py` | MCP 协议握手/帧格式/工具契约/识别功能/错误处理/批量,模型主动调用通道的契约 | 秒级/免费 |
| 集成(真实 API) | `test_regression.py` | 8 项关键路径回归(真实视觉 API) | 分钟级/花钱 |
| 多轮模拟(真实 API) | `test_multi_round.py` | 轮次隔离、时间戳递增、state 无累积 | 分钟级/花钱 |
| 交接质量(真 DeepSeek) | `test_handoff.py` | 真正的 DeepSeek 作为主模型:最新轮/历史轮/图号/相似不混淆 | 分钟级/花钱 |

## 运行

```bash
python run_all.py            # 全部(快速档 + 慢速档)
python run_all.py --fast     # 快速档(秒级,每次改动必跑)
python run_all.py --slow     # 慢速档(nightly 或发版前)
python <单个测试文件>.py     # 单独运行
```

结果写入 `last_result.json`(时间戳、commit、各套件通过率),供趋势追踪。

## 基础设施

- `_mock_api.py`:本地 mock 视觉 API(故障注入开关 + 请求记录),快速档全部确定性、无真实网络
- 关键验证:`test_fault_injection.py` 用例 6 断言"用户问题不传给视觉模型"(建议物理隔离)

## 迭代进化机制(走向自我验证)

1. **Bug 驱动生长**:每次线上/实测发现异常 → 固化为测试用例(红)→ 修复(绿)→ 永久保留。
   攻击集与回归集是同一资产的两面。
2. **双层 CI 节奏**:快速档每次改动全绿才合入;慢速档发版前跑(真实 API + DeepSeek eval)。
3. **版本化结果**:`last_result.json` 记录每次运行,趋势追踪;eval 分数漂移可区分
   "上游 API 变了"与"我们坏了"。
4. **突变测试(规划)**:用 mutmut 对纯逻辑层跑,验证测试套件本身的有效性
   (测测试的测试),分数下降必须解释。
5. **LLM-as-judge(规划)**:识别事实性打分,标定与人工一致性(κ≥0.6)后才启用。
6. **人工黄金集(规划)**:10-20 张代表图 + 人工标准答案,每版本记录准确率趋势。

## 已知被本体系抓到并修复的问题

- L1 模糊:非 dict payload(JSON 数组)导致 hook 崩溃 → 已修复(类型防御)
- 测试自身:session 路径拼接误解、Windows 文件名长度限制、重复 put 导致 mtime 变化
- 残图攻击集:贴错图→删图→换图→提交,旧图(从未发送)被识别注入 → 已修复
